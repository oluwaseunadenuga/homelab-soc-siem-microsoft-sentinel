# Azure Honeypot Deployment

## Objective

Deploy an isolated Windows VM to generate security telemetry for SOC monitoring.

## Documented Activities

1. Created/selected an Azure subscription.
2. Created a Windows VM.
3. Configured administrator authentication.
4. Configured networking and an NSG.
5. Connected to the VM.
6. Validated Windows Event Viewer.
7. Generated controlled failed authentication events.
